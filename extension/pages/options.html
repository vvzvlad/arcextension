Enter the address of the service — curator.example or curator.example:8443. The scheme is added for you: wss://, or ws:// for localhost / 127.0.0.1 / [::1] in development. An unencrypted address is not accepted, because this instance's secret and the enrollment code travel over this connection as-is and TLS is the only thing hiding them — so an explicit http://, or ws:// to anything but loopback, is refused. A full wss://… URL keeps working unchanged.


1–64 characters of A–Z a–z 0–9 . _ - — no spaces. This is the name the service knows this browser by: it appears in the admin console, in curation rules and in metrics. It must not be taken by another live browser; a name freed by revoking a browser can be reused.

Dangerous operations (§12)

When off, the service cannot run arbitrary JavaScript through this extension: every execute_js command is refused with js_disabled and nothing is executed. Default: off.
