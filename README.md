# arcextension — куратор вкладок

Реконструкция механик Arc (Spaces / Air Traffic Control / Auto Archive / Library /
Command Bar) поверх нескольких изолированных инстансов Brave.

Каждый тематический браузер — отдельный `.app` со своим `--user-data-dir`. Сервис
следит за вкладками всех инстансов и постфактум сортирует их по правилам
«адрес → домашний инстанс», не мешая открывать что угодно где угодно.

## Компоненты

- `src/` — **curator-service**: Python-сервис (WSS-канал расширений, HTTP API,
  MCP over streamable HTTP, SQLite). Разворачивается в Docker на инфре.
- `extension/` — MV3-расширение для каждого инстанса Brave: репортит вкладки,
  исполняет команды, даёт попап для правил и newtab-стартпейдж.
- `startpage/` — Vue 3 + Vite, собирается в папку расширения.

## Как это работает

1. Расширение каждого инстанса держит исходящее WSS-соединение к сервису и
   зеркалит в него состояние вкладок.
2. Правило `pattern → instance` задаёт домашний инстанс для адреса. Правила
   заводятся в один клик из попапа расширения.
3. Раз в `PASS_INTERVAL_MIN` минут проход куратора берёт вкладки, которых не
   касались дольше `IDLE_MINUTES`, и переселяет их: с правилом — домой,
   без правила из тематического инстанса — в `main`. В `main` без правила
   вкладка живёт вечно.
4. Всё, что куратор закрыл или переселил, попадает в архив и восстанавливается
   в один клик.

## Запуск

```bash
make install           # .venv + dev/test-зависимости
cp .env.example .env   # заполнить значения
make test
make run
```

Полный дизайн, протокол и схема БД — в ишью майлстоуна «Куратор вкладок v1».
